# Amazon Sales Data Analysis Dashboard

## 📊 Project Overview
Is project mein Amazon ke sales data ka detail analysis kiya gaya hai. Isme **multiple data sheets** ko aapas mein connect karke ek interactive Excel dashboard taiyar kiya gaya hai, jo business ki performance aur delivery efficiency ko track karta hai.

## 🎯 Project Objective
Is project ka main goal sales trends ko samajhna, delivery status ko monitor karna aur actual sales ko set kiye gaye **Sales Targets** se compare karna hai.

## 📁 Data Columns & Features
Dashboard ko banane ke liye neeche diye gaye key data points ka use kiya gaya hai:
* **Timeline Tracking:** Order Date, Delivery Date, aur Cancel Date (Shipping performance check karne ke liye).
* **Customer Details:** Customer ID (Unique buyers track karne ke liye).
* **Financial Metrics:** Payment Method aur Sales Target (Achievement analyze karne ke liye).
* **Logistics:** Delivery Status (Success, Pending, ya Cancelled orders).
* **Product & Geography:** Category, Description, Region, aur City.

## 🛠️ Key Technical Highlights
* **Data Modeling:** Multiple sheets ko connect karke ek unified analysis framework taiyar kiya.
* **Interactive Dashboard:** Pivot Tables, Slicers, aur Dynamic Charts ka use kiya taaki data ko filter karna aasaan ho.
* **Performance Analysis:** Actual Sales vs. Sales Target ki visual reporting.
* **Data Cleaning:** Power Query aur Excel functions ka use karke raw data ko usable format mein badla.

## 🧰 Tools Used
* **Microsoft Excel** (Advanced)
